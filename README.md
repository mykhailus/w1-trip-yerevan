Сдача Михаила Яценко (@mykhailus) на неделю 1 группы «Хакатоны и короткие сборки». Поездку, инструмент и отчёт сделал агент (Claude Code), Михаил поставил задачу и проверил результат.

Синтетическая поездка: Ереван, 12–14 сентября 2026, пятеро, рубли и армянские драмы, 11 чеков, 2 возврата, 3 спорных пункта.

## Как проверить

```bash
python settle.py trip/data.json --check     # 5 контрольных фактов, код выхода 1 при ошибке
python settle.py trip/data.json -o report.md
python corrupt_test.py trip/data.json       # 7 порч входа
```

Только стандартная библиотека Python 3.9+.

## Что сделано так, чтобы работало на чужой поездке

Разборы этапа 2 (#37, #38, #40 в `hackathon-lab`) показали, что инструменты ломаются на чужих данных, потому что поездка зашита в код. Здесь в коде нет ни одного имени, суммы, валюты или факта:

- участники, валюты, курсы по датам, чеки, возвраты и спорное – только в `data.json`;
- на кого делится чек – поле `for`, по умолчанию все;
- возврат уменьшает долю тех, кто делил исходный чек, и уходит тому, кто его получил;
- контрольные факты – типизированные проверки в данных (`total`, `balance`, `not_in`, `counted_once`, `max_transfers`), а не строки в коде;
- на неизвестном человеке или отсутствующем курсе инструмент падает с понятной ошибкой, а не считает дальше.

## Что заметили по дороге

- **Контрольный факт поймал ошибку автора.** Баланс Даши при раскладке поездки был прикинут в голове как −4 638 ₽. Первый прогон показал красное: −626 ₽. Ручной пересчёт подтвердил инструмент: Даша заплатила 16 120 ₽ (R05, R11), получила возврат 2 640 ₽ (V01), её доля 14 106 ₽. Факт исправлен после ручной сверки.
- **Пять фактов ловят не всё.** Порча входа поймана в 6 случаях из 7. Пропущен один: возврат V02 записан Боре вместо Ани – общая сумма и баланс Даши от этого не меняются, а балансы Ани и Бори ни один факт не проверяет. Вывод для задания: пять фактов стоит выбирать так, чтобы каждый участник попал хотя бы в один.
- **Бот.** Отметка `started` через `POST /api/event` из PowerShell 5.1 (`Invoke-RestMethod`) получила `500 {"error": "внутренняя ошибка"}`, тот же запрос через `curl` прошёл с первого раза. Для агента на Windows это выглядит как сбой сервера; ожидался бы `400` с причиной.
